# Vite showcase

This is an independent React host. The JSON files in `public/documents/` are **hand-authored synthetic fixtures**, not genuine compiler output; their provenance hashes are placeholders. Replace them with trusted compiled manifests and their assets for a real publication.

Build the root package and install its packed tarball into this directory (for example, `npm install --no-save /absolute/path/to/marimo-blog-0.1.0.tgz`), then run `npm run build` or `npm run dev`. The site never invokes Python. The fixture illustrates only the currently represented outputs, not the complete output catalog.
