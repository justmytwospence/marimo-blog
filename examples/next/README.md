# Next.js App Router example

`content/showcase.json` is a **hand-authored synthetic fixture**, not genuine compiler output; its provenance hashes are placeholders. Replace it with a trusted compiled manifest and put its assets under `public/` for a real publication.

Build the root package and install its packed tarball into this directory (for example, `npm install --no-save /absolute/path/to/marimo-blog-0.1.1.tgz`), then run `npm run build` or `npm run dev`. The server reads and validates the manifest; neither site build nor requests invoke Python.
